# Practical 8 - Inventory Management Module (ADO.NET & CRUD)

## Setup Instructions
1. Run `Database_Setup.sql` in SQL Server Management Studio (SSMS) to create `InventoryDB` and the `Products` table.
2. Create an **ASP.NET Web Application (.NET Framework)** -> **MVC** project named `Practical8` in Visual Studio.
3. Copy the files from `Controllers`, `Models`, `Services`, `Views/Products`, and `Content` into your project.
4. Add the `<connectionStrings>` section from `Web.config` into your project's `Web.config`.
5. Run the project (`F5`) and navigate to `/Products`.
