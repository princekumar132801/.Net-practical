# Practical 9 - Placement Dashboard (Data Controls & Web Forms)

## Setup Instructions
1. Open **SQL Server Management Studio (SSMS)** and run `Database_Setup.sql` to create `PlacementDB`, tables (`Students` & `Placements`), and sample records.
2. Open **Visual Studio** -> Create a new **ASP.NET Web Application (.NET Framework)** project named `Practical9` -> Select **Web Forms** template.
3. Replace/Add `Site.Master`, `Default.aspx`, `Default.aspx.cs`, `CompanyDetails.aspx`, and `CompanyDetails.aspx.cs` into the project.
4. Add the `<connectionStrings>` section from `Web.config` into your project's `Web.config`.
5. Press `F5` to run the application.
